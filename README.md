# Nilanjan Chatterjee — Portfolio

[View the live website](https://nil68657.github.io/)

Personal portfolio for Nilanjan Chatterjee, a Principal Data Architect specializing in enterprise data platforms, Lakehouse architecture, Data Mesh, AI, MLOps, and governance.

## Technology

- React and Vite
- Responsive, accessible plain CSS
- GitHub Actions and GitHub Pages

## Run locally

```bash
npm install
npm run dev
npm run build
```

## Deployment

Updates to `main` are automatically deployed to GitHub Pages.
